Cobblemon Cards Fakemon resource-pack template (Minecraft 1.21.1)

1. Replace and rename regular/examplemon.png and shiny/examplemon.png.
2. Use 48x32 PNGs: draw in the top-left 40x30 area, with transparent padding.
3. Edit or remove the optional Examplemon translations under assets/cobblemon/lang.
4. Enable this ZIP on every client. The matching server datapack controls drops and boosters.

Guide: docs/CUSTOM_FAKEMON_SPRITES.md in the Cobblemon Cards repository.
