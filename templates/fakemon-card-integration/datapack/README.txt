Cobblemon Cards Fakemon datapack template (Minecraft 1.21.1)

1. Edit data/cobblemon-cards/fakemon_cards/example.json.
2. Replace "examplemon" with the lowercase internal Species name, without a namespace.
3. Install this ZIP in <world>/datapacks and run /reload.
4. Install the matching resource pack on every client for the card sprites.

Guide: docs/CUSTOM_FAKEMON_SPRITES.md in the Cobblemon Cards repository.
